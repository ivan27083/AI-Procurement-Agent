# AI-агент для первичной обработки заявок на закупку

Учебный проект для вымышленной компании ООО «Северная Логистика»: концепция AI-агента
«ЗакупКИ», который извлекает поля из свободного текста заявки, определяет категорию,
проверяет полноту и правила, ищет дубликаты, оценивает риск и готовит черновик карточки
и письма. Все внешние действия остаются за человеком.

**Готовый отчёт:** [`reports/AI-Procurement-Agent-Report.pdf`](reports/AI-Procurement-Agent-Report.pdf) —
41 страница, все шесть этапов, декларация использования ИИ и раздел «Решения и ограничения».

> **Данные синтетические.** Набор сгенерирован скриптом с `seed = 42` и имитирует выгрузку
> заявок за 2025 год. Компания, заявители, поставщики и цены вымышлены. Результаты нельзя
> переносить на реальный рынок; методика и ограничения разобраны в отчёте (разделы 3 и 9).

## Быстрый старт

Требования: Python 3.11+.

```bash
pip install pandas numpy scikit-learn matplotlib joblib markdown2 weasyprint Pillow
```

Полное воспроизведение (порядок важен — модель обучается на очищенных данных):

```bash
python scripts/generate_data.py      # синтетические данные, seed 42
python scripts/prepare_data.py       # очистка и производные признаки
python scripts/eda.py                # метрики и графики
python scripts/train_classifier.py   # обучение модели
python scripts/economics.py          # экономическая модель
python scripts/make_diagrams.py      # схема архитектуры
python scripts/make_screenshot.py    # скриншоты демо
python -m agent.cli --demo           # демонстрация агента
python -m unittest discover -s tests -v
python scripts/md_to_pdf.py reports/report.md -o reports/AI-Procurement-Agent-Report.pdf
```

## Использование агента

Демонстрационный набор (7 сценариев, результат сохраняется в `demo_output/`):

```bash
python -m agent.cli --demo
```

Одна заявка из текста:

```bash
python -m agent.cli --text "Нужен ноутбук Lenovo ThinkPad, 2 шт., 190 000 руб., бюджет IT-2025-04, обоснование: замена вышедшего из строя."
```

Свой JSON-файл со списком заявок:

```bash
python -m agent.cli --file examples/requests.json
python -m agent.cli --demo --json   # машиночитаемый вывод
```

Маршруты обработки:

| Маршрут | Значение |
|---|---|
| `AUTO` | данных достаточно, карточка готова, внешних действий нет |
| `CLARIFY` | не хватает обязательных полей, нужен запрос заявителю |
| `REVIEW` | требуется проверка закупщиком (порог, категория, риск) |
| `MANAGER` | дубликат или сумма ≥ 1 млн ₽ — решение руководителя |

Прототип **не отправляет письма и не создаёт заказы**: поле
`external_action_allowed` всегда `False`, все сообщения помечены
«ЧЕРНОВИК. Не отправлено.», каждая обработка пишется в `demo_output/audit_log.jsonl`.

## Ключевые результаты

| Показатель | Значение |
|---|---|
| Исходный → очищенный набор | 2 400 → 2 236 заявок |
| Удалено дубликатов | 164 (6,8%), ещё 68 помечены для человека |
| Классификатор категорий | accuracy 0,946; macro-F1 0,941 |
| Экономия времени (допущение) | 23 минуты на заявку |
| Годовой эффект / чистый эффект | 1 120 804 ₽ / 880 122 ₽ |
| Разовые затраты / постоянные в год | 1 100 000 ₽ / 240 681 ₽ |
| Окупаемость / точка безубыточности | 15,0 мес. / 2 688 заявок в год |
| NPV за 3 года при 20% | 918 317 ₽ |

Метрика 0,946 получена на синтетических шаблонных текстах; ожидаемая точность на реальных
заявках — 0,75–0,85. Экономика держится на допущении о 23 сэкономленных минутах: при 15
минутах окупаемость растягивается до 25 месяцев. Эти ограничения явно указаны в отчёте.
